# 注册中心文件查询

## 用途与边界

主模型通过统一搜索入口调用检索子智能体，组合文件名称、摘要条件，取得最终结果集，再分页查看文件ID、名称、来源平台代码、来源平台文件ID和通行证列表。沿用contract-service-be的候选引用、串行收窄、两表OR合并及排名融合思路，权威来源通过asyncmy只读访问，派生检索在内存中执行。

本模块只读注册中心权威文件及人员权限，派生正文、词频和向量仅在内存处理；不维护源文件、人员、权限或管理员关系，不下载PDF，不提供原件打开工具。原文件通过独立的[注册中心图像查看工具](registry-file-reading.md)通过平台认证和可信任务 userid 授权获取；查询工具本身不下载原件，也不向模型传入用户access_token。

---

## 检索反馈渲染

`search_files` 与内部名称、摘要、通行证、集合合并及完成工具均独立注册末尾渲染钩子，正文采用可直接审核的多行模板。程序使用原结构化结果与排名对象，模型收到可读回执，遵循[工具反馈渲染规范](../../../standard/tool-feedback.md)。最终排名只保存在本次子智能体工具会话中，不序列化为模型回执。

外层成功正文展示最终结果集 ID、候选文件数和 `view_file_candidates` 查看方向；子智能体提供的查询范围与限制放入资料文本边界，不作为程序执行指令。零候选明确未生成结果集 ID，保留本次范围说明，不把当前无可访问候选扩大为文件不存在。失败给出已知原因和下一步；失效引用、已关闭任务及内部定向反馈保留具体处理方向，未知失败不枚举多种猜测原因、不回显异常原文。

内部非空查询及合并回执展示完整候选结果集 ID 与数量，供后续收窄、合并或提交；空查询不生成 ID。参数与协议拒绝在调用前给出可读提示，失效候选引用在候选池校验附近给出重新查询方向，不能把失效集合当成空结果或擅自扩大范围。下一次成功后清除整段失败反馈，原始调用及结构化反馈仍保留于私有审计。通行证仍保留原值、大小写和首尾空格，不因规范化调用历史改变精确匹配。

`finish_file_retrieval` 成功直接结束子循环，没有下一轮内部成功消息；其引用不合法时仍可纠错。外层通过权限回查后准备结果集，仍由原 `after_commit` 发布；检查点提交失败不发布结果集。

`view_file_candidates` 已独立注册末尾渲染钩子，通过 `FoldableReceiptText` 提供展示、隐藏和不可读三种回执，保留最终结果集 ID、当前页/总页数、候选总数及下一步。模型当前可读时指向随后的文件资料；保存和历史恢复使用隐藏文本，不保存文件列表正文、不推断原文。文件名称、注册中心文件 ID、来源平台、来源文件 ID 和通行证仍在资料页展示，不重复塞入轻量回执。

`FileResultError` 可携带校验分支就近提供的原因与修正动作，分别说明失效引用、读取期间集合变化、已到末页、页码越界和回读越界。查看工具不直接回显任意异常字符串；读取依赖失败只说明读取未完成，不猜测删除或撤权。失败不推进页码。原有签名及 issued 引用限制继续有效，只有 journal 提交后的回调才推进页码并允许解析引用。

页面每次展示继续回查权限。单个候选已不可访问时，保留不可用占位，不回显旧文件 ID、名称或通行证；整页无法解析时选择不可读回执，不能从旧查看记录推断资料。候选总数是结果集建立时的排名数量，不等于当前仍可访问的文件数。

[文件候选查看测试](../../../../tests/test_file_candidates_feedback.py)验证两种主模式的实际反馈、页码错误纠正与审计、隐藏历史恢复、三态切换、候选撤权后的信息隐藏、依赖及回读越界失败、提交失败不签发引用或推进页码。使用模型与内存读取替身，未连接真实数据库或文件服务。

[文件检索反馈测试](../../../../tests/test_file_search_feedback.py)使用内存池、模型及后端替身，覆盖内部五工具、名称与摘要收窄、通行证原值、集合并集、失效引用纠错清理与审计；通过两种主模式验证命中、空结果、依赖失败及提交失败不发布结果集。未连接真实模型、注册中心数据库或向量服务。

## 主模型工具

| 工具 | 参数 | 成功结果 | SSE动作 |
| --- | --- | --- | --- |
| `search_files` | 必填`query`；可选`platform_codes`、`result_id` | 最终`result_id`、`count`、`explanation`；空结果无ID | `local-search`，正在检索注册中心文件：{query} |
| `view_file_candidates` | 必填`result_id`；可选`page` | 页码、候选数、是否还有下一页及可折叠页面引用 | `thinking`，正在查看文件列表 |

`query`保留用户完整需求、否定、必要条件与替代关系。`platform_codes`使用准确平台代码，省略/null不额外限制，空列表或重复项不合法；多个代码是平台范围的并集。它与当前授权及已有结果集取交集，不能恢复父结果集已排除的平台。

SSE 动作使用固定前缀和全角冒号，例如 `正在检索注册中心文件：采购合同，不含框架协议`。仅展示文案合并空白、移除不可打印字符，超出 2000 字符时加省略号；传给检索子智能体的完整 `query` 不受展示截断影响。

`result_id`必须来自当前任务成功提交的最终集合。省略/null从当前可访问范围开始；传入则仅在其候选中继续查找。引用无效或被驱逐时报错，不退回全库；平台交集为空正常返回零候选。

`page`从1开始。省略/null时首次第一页、此后下一页；显式页码可以重看；末页不循环。只有工具结果完成权威提交后才推进游标，失败不推进。不存在的结果引用与越界页码分别给出本地错误；数据库异常只返回脱敏不可用提示。

所有工具参数的实际JSON Schema都有字段说明；用户ID、权限等级、数据库路径、向量以及用户token都不是模型参数。

## 检索子智能体

| 内部工具 | 输入及职责 |
| --- | --- |
| `search_files_by_name` | 简短名称查询`query`、可选内部`result_id`；使用内存BM25关键词匹配。 |
| `search_files_by_passport` | 必填单个完整`passport`、可选内部`result_id`；精确匹配文件通行证数组成员，返回限定范围内全部匹配，不调用Embedding。 |
| `search_files_by_summary` | 基于已知线索拟写的正式摘要`query`、可选内部`result_id`；全文与向量混合召回。 |
| `union_file_results` | 两个内部结果引用`left_result_id/right_result_id`；并集去重及等权排名融合。 |
| `finish_file_retrieval` | 可选内部`result_id`及必填`explanation`；提交真实集合或明确无合适候选。 |

内部工具没有名单查看或PDF阅读能力，只返回引用、数量及必要反馈。`candidate-set:`引用不向主模型泄漏；收束后程序回读权威文件，生成独立的`file-query:`引用。名称/摘要候选是有限召回；通行证精确匹配返回当前范围的全部命中，两者都不代表未授权或其他范围的全库总数，也不证明摘要省略的原文条件已经满足。

AND使用父结果集限定后续查询。例如名称“采购协议”得到A，再在A内查询“验收后付款”得到B。OR从相同初始范围分别查询，再使用并集工具；不能串行收窄来替代OR。一表为空时直接选择另一表，两表为空不提交结果集。多路逐次合并的排序与结合次序有关，不将其宣称为一次全局等权融合，也不允许为了抬分反复合并同源证据。

主入口如引用已有最终集合，会传递初始候选范围与排名；子智能体省略内部引用只能回到这个初始范围，不能扩大到全库。精确通行证/平台/权限筛选保留历史相对顺序，不制造新相关性分数。相关性串行查询使用幸存集合的历史排名与本轮排名加权RRF；OR每表等权，不直接相加全文分数与余弦相似度。

每轮恰好一个真实工具调用，沿用模型工具协议模板和上下文预算。最多连续三次参数纠错，成功后清除连续失败反馈；成功历史只含工具调用与计数回执。原生推理、模型响应、失败分片及执行反馈以`file_retrieval`用途保存在当前节点私有生成记录，不混入权威工作区或主模型上下文。依赖失败、超时、轮数耗尽不发布部分结果；取消传播给外层任务。

## 按单个通行证查找

主模型仍使用`search_files`，在`query`中明确给出完整通行证，可通过现有`platform_codes`限制来源平台，例如：

```json
{"query":"查找持有通行证P-001的所有文件","platform_codes":["contract-pheno"]}
```

检索子智能体调用`search_files_by_passport`：`{"passport":"P-001"}`。每次只匹配一个完整通行证，大小写、首尾空格、逗号及看起来像JSON的业务字符串全部原样保留；不分词、不模糊匹配、不猜测值。值须为非空白字符串，最长512字符。一份文件可持有多个通行证，同一通行证可以对应多份文件；数组重复成员不会让文件重复出现，空数组及NULL不命中。

平台、用户文件等级和父结果集同时约束查询范围。通行证本身不授予读取权限。单次精确查询不受`FILE_RETRIEVAL_TOP_K`截断、不调用Embedding、不产生相关性分数；在名称/摘要结果内筛选时保留原排名。还可以在通行证结果内继续查名称或摘要（AND），或与另一结果取并集（OR）。随后沿用`view_file_candidates`分页展示文件ID、入库名称、来源平台代码和通行证列表，SSE仍为`local-search`并展示完整查找需求。

仓库只读查询现有`resources.passport`，不创建表或索引；字段需为注册中心已定义的JSON数组。查询后再次按同一通行证、平台和权限回读，资料或匹配成员变化时明确失败；数据库异常不能解释为没有匹配文件。结果集是查询时的候选快照，后续分页仍复核访问权限，不自动重跑原始条件或补充新增匹配文件，获取最新通行证成员应重新查询。

## 数据与授权

权威来源是配置的注册中心MySQL中的`resources`及`employees`：

| 来源字段 | 用途 |
| --- | --- |
| `resources.id` | 正式资源整数ID，工具用十进制字符串展示；不是UUID、`source_id`或磁盘文件名。 |
| `resources.source_id` | 文件在来源平台内的唯一标识，和来源平台代码共同定位；可为NULL，不能替代注册中心资源ID。 |
| `resources.name` | 名称全文检索及列表展示。 |
| `resources.passport` | 读取后保留为不可变序列供候选列表查看工具展示；可空JSON字符串数组；使用`JSON_CONTAINS(passport, %s)`精确匹配单个成员，参数经JSON编码后绑定。 |
| `resources.abstract` | 摘要全文检索与向量生成。 |
| `resources.source_platform/file_level` | 文件来源平台代码和文件访问等级。 |
| `employees.userid/platform_permissions` | 大小写精确的可信用户身份、对应平台文件权限。 |

只允许文件等级非null、用户具有该来源平台键且用户等级不低于文件等级的资源。缺少员工或平台键不会按默认0级放行；管理员身份不提供文件读取旁路；非法权限JSON或数据库错误直接失败。开发环境同样使用SQL中的真实权限，不从配置模拟管理员关系或初始身份快照补权限。

源读取在只读一致性事务中完成，查询、收束、分页解析均重新核对来源。检索期间所选文件的资料或等级变化会拒绝发布陈旧命中；最终收束过滤已不可访问项。列表历史排名不重新查询补齐，已删除或撤权项只显示“此候选已不可用”，不再次暴露其名称和ID。该机制不是跨数据库写事务，不能保证用户已经看到的内容在之后撤权时从其记忆中消失。

## 检索索引与配置

[内存索引](../../../../app/infrastructure/file_search_index.py)不接收数据库连接，只对本次已授权资料生成词频并排名，不新建或写入文件检索表。每次查询正常结束、失败或取消后释放正文词频和当前在用向量；最终结果集仍按既有任务级LRU管理。

摘要向量由每进程有界LRU复用，容量为`FILE_RETRIEVAL_CACHE_MAX_VECTORS`。键包括文件身份、平台、正文、模型、维度、模型地址、归一化选项和编码指令；内容或编码契约变化会生成新键，旧版本按LRU淘汰。向量命中不能替代权威权限查询；只有本次读取的已授权键参与排名，其他用户已缓存文件不参与词频统计或候选截断。单次授权范围即使超过LRU容量，也保留全部在用候选至本次查询结束，不因缓存容量遗漏文件。

源`resources.embedding`没有完整编码契约，不直接混用；摘要按本项目[基础文本编码指令](../../../../app/agent/core/prompt/embedding.py)生成向量，查询使用相同协议。名称检索不调用Embedding；摘要检索需要`VLLM_EMBEDDING_*`，但不需要MyVector或任何派生数据库表。模型或权威源故障明确失败，不静默降级为无结果或单路成功。

关键词使用纯Python内存BM25（k1=1.2、b=0.75，正值平滑IDF）；参照[信息检索教材的词频饱和与长度归一化定义](https://nlp.stanford.edu/IR-book/html/htmledition/okapi-bm25-a-non-binary-model-1.html)。统一NFKC、大小写后，汉字按单字及相邻双字切分，其他文字按连续字母数字切分，标点为边界；这是字符粒度匹配，不宣称等同于语义中文分词、原MySQL全文或源项目Lindera分词器的结果。查询词去重，不解释SQL或布尔查询语法，AND/OR仍由候选集合工具组合。

向量使用内存归一化精确余弦计算；关键词与向量均只对当前权限、平台和父集合范围排名，每路取`top_k × candidate_multiplier`，摘要按RRF融合后截取top_k。没有余弦阈值，可能包含弱相关候选，分数不是概率。CPU分词和排名在线程执行，服务锁隔离不同查询的临时快照；取消后的只读计算即使尚未退出，也不能把结果回写已释放索引。

进程重启、关闭或向量淘汰后按需重新编码。首次查询仍可能读取整个授权范围并批量编码摘要；向量LRU容量不限制单次快照内存峰值，本轮不宣称大规模语料性能已验证。
| 配置 | 默认 | 用途 |
| --- | --- | --- |
| `FILE_SOURCE_MYSQL_DATABASE` | `registry` | 权威资源与人员所在schema，须部署时明确对齐。 |
| `FILE_SOURCE_MYSQL_HOST/PORT/USER/PASSWORD` | 留空复用本项目`MYSQL_*` | 可设置独立只读源账号，仅需SELECT资源与员工表。 |
| `FILE_SOURCE_MYSQL_CONNECT_TIMEOUT_SECONDS/OPERATION_TIMEOUT_SECONDS` | 复用`MYSQL_*` | 可选源连接与查询超时。 |
| `FILE_RETRIEVAL_TOP_K` | 10 | 单次查询最终候选数。 |
| `FILE_RETRIEVAL_CANDIDATE_MULTIPLIER` | 4 | 混合召回每路候选倍数。 |
| `FILE_RETRIEVAL_CACHE_MAX_VECTORS` | 256 | 每进程摘要向量LRU条数；关闭释放，无磁盘持久化。 |
| `FILE_RETRIEVAL_CACHE_MAX_QUERIES` | 10 | 单次检索内部池及当前问答最终池各自的LRU容量。 |
| `FILE_RETRIEVAL_PAGE_SIZE` | 5 | 最终列表每页候选位置数。 |
| `FILE_RETRIEVAL_MAX_ROUNDS` | 16 | 子智能体最大生成轮数。 |
| `FILE_RETRIEVAL_RRF_K` | 60 | 内部双路及跨查询融合常数。 |
| `FILE_RETRIEVAL_HISTORY_WEIGHT` | 0.5 | 串行查询的历史排名权重，本轮权重为1减该值；OR不使用该权重。 |

示例见[.env.example](../../../../.env.example)。本功能没有自动读取外部项目配置，也不要求新增前端参数；本轮没有修改实际.env、执行共享数据库DDL或访问真实注册中心。

## 分页正文与生命周期

```text
# 文件查询结果

第 1 / 2 页 · 本次召回 6 个候选

1. **文件名称**：设备采购协议.pdf
   **文件 ID**：`101`
   **来源平台代码**：contract-pheno
   **来源平台文件 ID**：` contract-2026-001 `
   **通行证**：`P-001`、`P-002`

2. **文件名称**：设备采购补充协议.pdf
   **文件 ID**：`102`
   **来源平台代码**：contract-pheno
   **通行证**：`P-001`

……

还有下一页。
```

实际页按配置列出对应数量。每条包含文件名、ID、来源平台代码、来源平台文件ID和通行证列表。来源平台代码直接使用本次权威回读的`resources.source_platform`，不从查询筛选条件推测，也不额外请求平台目录转换名称；不附摘要、等级或排名分数。名称中的换行、Markdown控制字符和HTML标记作为数据处理，不能伪造另一条列表或标题。轻量回执只存页码元信息和签名资料引用，正文沿用`AGENT_PAGE_DISPLAY_ROUNDS`自动折叠；只有提交后的引用可解析，解析时重新读取权威名称、通行证与权限。

来源平台文件ID直接读取`resources.source_id`，不从注册中心ID、文件名或通行证推算。NULL显示“资料未提供”；原值保留大小写、空格和标点，以与通行证相同的安全行内代码格式展示。向来源平台协作时使用平台代码和该ID定位文件，本地原文阅读继续使用注册中心文件ID。分页每次回读最新值，撤权后不展示该标识。

通行证直接读取`resources.passport` JSON数组，按登记顺序以行内代码展示，各项使用顿号分隔；保留重复项、大小写和首尾空格，控制字符采用可见转义，反引号使用动态代码边界，不能伪造列表或链接。空数组显示“暂无”，NULL显示“资料未提供”。非法数组明确报错，不伪造空列表。通行证只展示在可折叠候选列表正文，不进入轻量回执或SSE，也不添加到PDF图像查看工具中。每次展示复核权限并读取最新值，撤权后不回放旧通行证。

每个正在执行的问答任务独立创建最终结果池；助理和探索通过可选`file_retrieval`依赖使用相同实现。正常结束、失败、取消或方向调整结束旧任务后释放结果池，迟到提交不能恢复已关闭集合。分页游标及结果引用不跨用户、任务或重启恢复，节点历史只保留轻量工具记录。组合根延迟建立源数据库连接，停机先等待问答结束，再关闭检索来源及模型/数据库依赖。
