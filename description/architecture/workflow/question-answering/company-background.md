# 公司背景与默认指代

## 用途与范围

Core 的稳定系统提示词包含现象创新（深圳）科技有限公司的公开业务背景，让探索问答和个人助理理解公司业务、研发术语和默认指代。公司全称由需求方确认；公开介绍用于辅助理解，内部业务事实仍由实际资料与工具结果支持。

模型可见正文维护在 [company.py](../../../../app/agent/core/prompt/company.py)，本页记录来源、装配和维护方式，不复制完整提示词。

---

## 默认指代与使用方式

没有明确的其他上下文时，“我们公司”“公司”“本公司”“咱们公司”均指现象创新（深圳）科技有限公司。已有明确客户、供应商等企业指代时，继续沿用；只有歧义影响实际结论时才澄清。

| 用户问题 | 预期处理 |
| --- | --- |
| 公司最近有什么活动？ | 直接查询现象创新，核对日期和资料，不重复询问公司名称。 |
| 整理这组 SAM 实验 | 结合界面材料背景，按实际配方、基底、工艺和测试条件整理证据。 |
| 正在讨论客户甲，随后问公司审批找谁 | 沿用客户甲的指代，并查询对应审批资料。 |
| 我们产品是否达到某项性能？ | 查询具体型号和测试证据，不能用公司整体介绍替代确认。 |

## 公开资料与采用范围

检索核对时间为 2026-10-26（Asia/Shanghai）。官网为动态页面，除搜索索引外，核对了官网公开页面及其静态脚本中的中英文正文。

| 来源 | 可支持的内容 | 采用方式 |
| --- | --- | --- |
| [公司官网](https://www.phenosolar.com/?lang=en) | AI 与高通量工程、SAM 界面材料、有机合成、纳米结构材料，以及公开应用方向。 | 作为公司自述定位；应用方向不等于成熟产品或商业交付。 |
| [Pulse 官方介绍](https://www.phenosolar.com/pulse/) | 材料研发闭环、知识与数据整理、候选规划、计算筛选、实验验证、反馈学习，以及 PhenoMind。 | 提炼业务含义，不将官网系统名称解释为本助手已获得工具或设备权限。 |
| [公司 CEO 在世界经济论坛发表的材料创新文章](https://www.weforum.org/stories/technological-innovation/the-next-climate-breakthrough-may-come-from-materials-too-small-to-see) | 界面材料、SAM、实验条件和可制造性的重要性，以及 AI、实验与反馈之间的关系。 | 辅助解释研发视角；作者观点与公司自述不能替代具体实验结论。 |

提示词保留业务定位、研发闭环和术语理解，不固定注入宣传性能数字、融资与注册资本、员工人数、管理层姓名、联系方式或未经核实的产品参数。公开资料中的效率、规模及“领先”等表述不能作为通用、独立验证的结论。

近期活动、客户订单、合同、研发进度、员工安排等属于需要查询的具体事实。公开背景不包含内部实时数据，不意味着工具已接入，也不授予对外承诺权限。未查到资料时应说明缺口，不能推断公司没有相关事项。

## 装配、依赖与维护

[Core 提示词入口](../../../../app/agent/core/prompt/__init__.py)通过 `build_system_prompt()` 按角色、公司背景、交互规则、工作区规则组合。探索与助理的角色构建器复用该入口；助理四种任务类型继续追加各自的任务和交付要求，公司背景只注入一次。员工资料仍按[个人信息与画像](assistant-personal-context.md)作为本轮资料加载，不提升为系统指令。

调用者显式传入完整 `AgentCore(system_prompt=...)` 时继续使用该自定义正文，不额外修改。拥有独立提示词的外部专家、检索与压缩子流程不因此自动获得公司背景。

本功能无需数据库迁移、配置开关或运行时联网抓取。来源日期和维护说明只保存在本文，不作为模型可见的工程元信息。公司定位变化时人工复核来源并更新常量；业务请求中的实时事实仍需按当轮资料核实。服务未开启自动重载时，修改后需要重启进程。

## 验证边界

验证实际 Core、探索及个人助理四种任务的消息装配，检查系统消息仅包含一份公司背景，同时保留所属用户资料隔离。既有个人上下文及 A2A Core 回归用于检查公共提示词调整对消息装配和工具循环的影响。

这些验证不调用真实模型，不能证明模型在所有语境下都正确消解公司指代；上线后可使用上述示例检查实际回答及工具查询对象。

2026-10-26 验证结果：六种实际消息装配及完整提示词自定义覆盖检查通过；既有 `test_assistant_personal_context`、`test_platform_a2a_core` 共 14 项测试通过；提示词模块编译、新增文档引用与导航链接、`git diff --check` 检查通过。未进行真实模型语义测试。
