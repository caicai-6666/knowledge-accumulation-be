# 网页搜索与正文读取

## 用途与装配

将 contract-service-be 的网页工具契约迁入公共 Core：先检索候选，再分页看摘要，最后按关注重点读取、筛选图片并精炼所选网页。搜索摘要不能当作已读取或已核实的正文。基础工具参数与文字页面渲染沿用参考项目，图片筛选与图文精炼在此基础上扩展；按本项目提示词规范，将两处字段说明和过期反馈中的缓存/驻留术语改为正文是否仍可读取，不暴露内部缓存机制，适配当前[工具提交与折叠机制](tool-content-contract.md)。

入口为 [web_search.py](../../../../app/agent/core/tool/web_search.py)、[web_page.py](../../../../app/agent/core/tool/web_page.py) 和 [web_page 子图](../../../../app/agent/core/subgraph/web_page/workflow.py)。`QuestionAgentService` 按可信 `(userid, tree_id)` 装配，探索和助理模式共用；无资源的基础 `build_core` 仍可独立使用，宿主也可通过注册函数显式注入这三个工具。

`search_web` 直接调用 DeepSeek Search HTTP 接口，不用模型路由；[外部专家](external-expert.md)仍调用 Responses。两者共用已有 DeepSeek 身份，搜索和生成预算独立。网页正文精炼使用本项目 vLLM MLLM，不消耗专家 Responses 会话。

## 三个工具

| 工具 | 参数 | 行为 |
| --- | --- | --- |
| `search_web` | `query` | 1—128 字符检索词。成功仅返回 `result_id/count`，不自动展示第一页。空结果不生成 ID。 |
| `view_web_search_results` | `result_id`、可选 `page` | 查看标题、URL、搜索摘要和来源标识。省略页码首次看第 1 页，其后看下一页。 |
| `open_web_page` | `source_id`、可选 `focus/keywords/page` | 首次读取或正文失效时需 focus；同一 focus 复用精炼图文。第一页展示相关图片，指定 page=1 可重看。换 focus 重新抓取和精炼。 |

检索支持 `site:`、引号词组、`after:`、`before:` 等供应商语法。复杂问题拆分检索，超长 query 明确拒绝，不静默截断。结果保持供应商原始顺序；模型只看到业务标题、链接、摘要和检索时间，不看到供应商路由、排名诊断或私有审计。

`source_id` 为搜索列表提供的完整来源标识，不能使用行号、结果集 ID 或任意 URL。`focus` 首次为非空文字、最多 4000 字符；`keywords` 最多 5 个、每个最多 24 字符，仅用于用户动作提示，不传入精炼模型、不参与缓存键。页码从 1 开始；非法页或到达末尾不推进游标。

网络失败、鉴权/额度/限流错误与成功零结果严格区分。面向模型的搜索失败回执为 `search_failed`，不会伪装为空结果；供应商状态码及脱敏响应留在当前用户树的有界私有搜索审计中。

## 网页读取子图

执行顺序为 `HTTP 读取 → 正文与候选图片提取 → 有界图片读取 → MLLM 图文精炼 → finalize`。任一步失败直接收束，跳过余下步骤；不会用搜索摘要填补缺失正文。

HTTP 默认总时限 30 秒、解压后上限 3 MiB、最多 5 次重定向，仅接受 HTML/XHTML。每次独立客户端，不携带应用登录凭据，不使用环境代理，不跨网页保存 Cookie；拒绝带用户名/密码的 URL。首次请求失败、超时、网页为空、类型不符或超限均不启动精炼。没有可用文字但存在候选图片时仍可继续；文字与图片都不可用时明确失败。网页本身可以正常重定向；带 API Key 的搜索请求始终不跟随重定向。

Trafilatura 在线程中保留链接与表格、去除评论；lxml 提取页面真实可见的登录、验证码、订阅等限制线索，另附到精炼输入，防止正文提取丢掉必要限制。页面有“登录”入口本身不等于无正文。

精炼使用普通 Chat Completions，不强制服务端 `response_format/json_schema`。提示词要求输出 `evidence/reasoning/type/result/selected_images`，本地严格校验；`type=content` 才能发布正文，`no_content` 返回具体原因。只保留与 focus 相关且能明确归属的信息及条件，不补写外部事实，不混淆主商品和推荐商品。最多 3 次输出校验尝试；纠错只加入最小固定反馈，不把失败 JSON、半成品或原生推理重新注入。网络故障不自动重放生成。

每次精炼的完整原生响应、推理、验证结果与失败/取消记录保存到当前节点 `question_node_generations.payload`，`purpose=web_page_refinement`；不需要 SQL 迁移。生成状态 complete 表示收到了完整原生消息，业务是否接受另见私有事件 `accepted`。不采用窗口截断，不因正文 LRU 驱逐而删除这些记录。公开树及 SSE 不暴露私有生成。

## 网页图片筛选与任务内存

图片提取与下载见 [image.py](../../../../app/agent/core/subgraph/web_page/image.py)。从 article/main（不存在时回退页面）中的 img 提取 src、常见懒加载地址与 srcset 候选，保留 figcaption、alt 和附近正文；过滤导航、明显广告/图标、极小图及重复 URL。下载后再按规范化图像内容去重。不是独立图片搜索，不执行 JavaScript，也不截取整页；CSS 背景图、SVG、动态 GIF/WebP 和必须登录的图片本轮不支持。

每页默认最多读取 6 张候选、保留 3 张；每张下载及标准化后不超过 4 MiB，源图最多 1600 万像素，最短边至少 48 像素；图像按 EXIF 方向处理、透明区域置白、最长边缩至 1280 像素并转换为 PNG。整个图片读取阶段上限 15 秒。数量、大小受限，因此不能声称已看完网页的所有图片或精确辨认缩小后不清晰的细节。

仅接受无账号密码的公开 HTTP/HTTPS 图像地址及常用端口。DNS 必须解析为公网地址；连接固定已校验 IP，HTTPS 使用原域名 SNI/证书校验，逐次重定向重复检查，最多 3 次重定向。图片请求不携带应用身份，不使用环境代理，不跨请求或重定向传递 Cookie；HTTP 类型声明和 Pillow 实际解码都必须通过。

精炼模型接收正文和候选图片的原生 image_url 内容块，按 focus 选择相关图表、结构图或细节图。selected_images 只能选择本次实际提供的整数编号，拒绝布尔值、字符串、重复编号、虚构编号、超出保留数及 no_content 带图。模型输出异常沿用最多 3 次纠错，失败输出只保存在私有审计，后续精炼输入不携带失败 JSON。无图时使用纯文字输入；图片失败但正文可用时仍返回正文，并明确图片未核实。

open_web_page 的第一页同时返回正文和筛选后的图片引用；主模型直接看到真实图像及网页来源、图注，工具回执不包含 Base64。图片与正文分别声明媒体类型，共享原生分词/生成输入及 AGENT_PAGE_DISPLAY_ROUNDS 展示窗口，翻到后续文字页不重复展示图片，重看第 1 页会生成新的展示引用。依赖的 MLLM 必须支持图像 Chat Completions。

图片字节及带图片快照只驻留本次问答内存：完成、取消、失败、改变方向结束旧任务、树释放或停机均清理；同树并发任务通过独立作用域隔离，迟到响应不能恢复已经释放的图片。图片会随网页 LRU 提前释放，此时展示层明确标记当前不可读，不伪造图像也不中断其他资料展示。纯文字网页缓存继续沿用既有树级生命周期。下一任务需使用 source_id 和 focus 重新读取图片，不恢复旧图像快照。

不新增数据库表、文件资源路由或图片附件，不写 data/user/upload-file，不把输入图片字节写进原生生成审计。模型生成的图像观察文字、精炼结果和已提交的轻量工具引用仍按既有节点记录规则保存；“释放图片”不删除这些已生成文字。前端不接收网页图片文件或图片流。

## 分页、LRU 与折叠

每棵用户树分别维护搜索结果池和正文池；带图片的精炼快照另绑定当前任务，退出本轮租约即释放。同一链接换 focus 后不得复用旧精炼结果；当前不建立第二套原始 HTML 缓存。正文按最终文本连续切片分页，顺序拼接可恢复完整精炼正文，不擅自缩短。

| 资源 | 默认容量/分页 | 驱逐后的行为 |
| --- | --- | --- |
| 搜索结果池 | 10 个查询，每页 5 条 | 来源映射随结果集释放；需重新搜索。 |
| 精炼正文池 | 10 个 `(source_id, focus)`，每页 3000 字符 | 来源仍有效时可指定 focus 重新读取，否则需重新搜索。 |
| 用户树宿主 | 32 棵用户树 | 仅 LRU 驱逐没有活动任务的宿主；全部在用则明确失败。 |

[WebSessions](../../../../app/agent/core/web.py)在每轮任务持有租约，防止执行中被另一棵树驱逐。删除树先等待生产者结束，再清理两类资源；停机同样先取消/等待生产者，再释放缓存。驱逐后的迟到响应不能重新写入已关闭资源。同树跨节点可以读取仍驻留的纯文字结果，图片及其图文快照不跨任务继承，不能跨用户或跨树使用来源标识；进程重启后标识过期，不伪装恢复成功。

搜索页、正文页与选中图片均为 `foldable`，正文和图片只在页面解析时注入模型，权威工具回执只保存引用与轻量元数据。沿用 `AGENT_PAGE_DISPLAY_ROUNDS`，默认 5 次完整主模型响应后自动折叠，不是最多 5 个页面。

适配当前 Core 的两个必要点：每次重新打开都生成独立展示标识，避免重新打开同页被误判为重复；分页游标经 `ToolExecution.after_commit` 在节点权威提交成功后推进，数据库失败不跳页。签名绑定资源、位置和展示标识，可检查篡改与跨会话引用，无需积累无界的引用表。

## 模型实际页面展示

搜索页与源项目使用相同正文模板，标题、候选顺序和完整来源标识保留：

```text
# 搜索结果

结果集：web-search:〈完整UUID〉
检索词：官方 申请条件
检索时间：〈带时区时间〉
第 1 / 2 页 · 共 8 条
网页摘要不等同于已读取正文。

## 1. 官方申请指南
来源标识：web-source:〈完整UUID〉
链接：https://example.org/application
搜索摘要：申请条件及办理流程……

可继续查看第 2 页。
```

```text
# 网页精炼内容

标题：官方申请指南
来源标识：web-source:〈完整UUID〉
链接：https://example.org/application
抓取时间：〈带时区时间〉
关注重点：申请条件
第 1 / 1 页

〈模型精炼正文，保留条件、例外及访问限制〉

已到最后一页。
```

上述正文由统一资料消息包络展示，网页内容始终作为外部资料；不提升为系统指令。完整页面不放进成功工具回执，因此页面折叠后不会通过回执重复泄露全文。

## 动作提示与 SSE

三个工具的动作提示沿用源项目 `online-search` 类型，`keywords` 只改变用户可见提示：

| 工具 | 状态示例 |
| --- | --- |
| `search_web` | 正在搜索网页：官方 \| 申请条件 |
| `view_web_search_results` | 正在查看搜索结果 |
| `open_web_page` | 正在读取网页：条件 \| 截止日期 |

工具结束后恢复 `thinking/正在思考`。状态只说明动作，不代表成功；成功、失败以工具回执为准。探索运行通过原 SSE 流新增 `task.progress` 事件，包含 `turn_id/type/message`，遵守原事件回放和终态约束，详见[订阅接口](../../../api/exploration.md#订阅并激活探索任务)。不创建新 HTTP 路由，不写公开消息表；动作事件由探索任务的展示历史单独持久化，打开树可恢复。

## 依赖与配置

已声明并安装 `trafilatura==2.3.1`、直接依赖 `lxml==6.1.3`；LangGraph、httpx、OpenAI SDK 和 MLLM 客户端复用已有实现。下表配置由 `.env.example` 说明。网页图片本轮仅补示例，没有修改实际 `.env`；未显式配置时使用代码默认值。专家的 Key 和地址复用，不复制其他项目配置。

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `DEEPSEEK_SEARCH_TIMEOUT_SECONDS` | 45 | 搜索 HTTP 总时限，范围大于 0 且不超过 300 秒。 |
| `DEEPSEEK_SEARCH_COUNT` | 10 | 单次候选条数，1—50。 |
| `DEEPSEEK_SEARCH_TRUST_ENV` | false | 是否使用环境代理；默认关闭。 |
| `AGENT_WEB_SEARCH_CACHE_MAX_QUERIES` | 10 | 每棵用户树的搜索结果集容量。 |
| `AGENT_WEB_SEARCH_PAGE_SIZE` | 5 | 搜索每页条数。 |
| `AGENT_WEB_SEARCH_MAX_CONCURRENT_REQUESTS` | 2 | 同一 QuestionAgentService 的共享搜索并发额度。 |
| `AGENT_WEB_PAGE_CACHE_MAX_ENTRIES` | 10 | 每棵用户树的精炼正文容量。 |
| `AGENT_WEB_PAGE_CHARS` | 3000 | 正文每页字符数。 |
| `AGENT_WEB_IMAGE_MAX_CANDIDATES` | 6 | 每页候选图片数，1—20。 |
| `AGENT_WEB_IMAGE_MAX_SELECTED` | 3 | 每页最多保留给主模型的图片数，1—6。 |
| `AGENT_WEB_IMAGE_MAX_BYTES` | 4194304 | 单图下载及标准化字节上限，最大 16 MiB。 |

搜索请求精确为 `POST /v1/tools/search`，body 为 `query/count/need_content:false`；已有 base URL 以 `/v1` 结尾时不重复拼接。缺少 Key 不发送请求；搜索服务有界并发、取消释放额度、不自动重试。配置修改后重启服务。
