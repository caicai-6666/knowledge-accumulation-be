# 多轮 Agent 上下文与记忆管理规范

## 分层与生命周期

| 层 | 内容与生命周期 |
| --- | --- |
| 稳定前缀 | 通用角色、交互和工作区规则，任务内不改写。 |
| 权威工作区 | 已通过结构、引用和状态校验的四区域精简信息。 |
| 有效短期轨迹 | 已成功提交的 assistant/tool 对，必要时压缩成摘要。 |
| 临时纠错 | 连续失败期间的最小反馈与合法协议的失败调用；下次动作完整成功后全部清除。 |
| 私有审计 | 每次完整生成、推理、原始流片段及失败信息；永不因清理模型记忆而删除。 |
| 下游状态 | 只包含已提交的工作区、公开消息及终态。 |

不能用同一 messages 列表同时承担六层职责。普通文本、失败调用及半成品不能进入权威工作区或已接受轨迹。用户输入和资料始终作为数据，不提升角色。

---

## 单轮处理

先完整记录原始生成，再校验唯一工具、参数、状态和业务规则。错误反馈只保留必要字段位置、问题与修正方向；不回显原始无效参数或异常堆栈。所有连续失败共用边界，不因工具名或 JSON 恢复正常就提前清理。

只有动作全部通过并成功提交，才清空整段临时失败轨迹、重置恢复计数，并加入正确动作或从最新工作区重建上下文。提交结果不确定时停止，不自动重放。成功提交的最终输出即结束本轮，不能因发送回调失败再次生成。

---

## 树、工作区与容量

选择一个节点时，从该节点向根寻找首个摘要，仅注入该摘要和其后的有效路径；绝不使用未来分支摘要。工作区恢复为所选节点的版本。摘要是新节点，不能覆盖历史节点。

使用模型原生分词接口计数，禁止字符估算；预留输出和管理容量，硬上限前整理有效历史和工作区，整理结果也须计数验收。压缩失败不删除原始信息、不提交半成品、不继续超预算请求。原生推理完整留存但不自动重注入。

工作区只保留继续任务所需事实、来源、用户约束、探索结论及剩余计划。压缩通过显式校验工具精简、合并或删除冗余条目；先维护引用再删除，不能悬空引用。保护路径及原值不可变，保留的既有信息确认状态和探索结果不可变，不新增业务探索成果。有效要求、关键事实和必要来源必须保留；自然语言措辞允许精简，不能以结构验收代替语义保真评估。

---

## 隔离与检查

每次运行独立持有轨迹、工作区副本、恢复计数及审计。用户和节点身份由程序绑定，不放入模型工具参数。并发共享模型配额不意味着共享上下文。

测试至少覆盖：正常动作、多工具、普通文本、JSON/Schema/状态错误、连续混合纠错成功后的完整清理、私有生成仍完整、轮数和恢复上限、压缩前后预算、取消、故障不提交、终态冻结、并发隔离和历史分支选择。
