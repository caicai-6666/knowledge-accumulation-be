# 助理一日场景与三用户实验

本专题记录助理端到端实验的复现入口和验收边界。服务职责见[消费与交付](assistant-consumption.md)、[钉钉入站](assistant-inbound.md)、[定时任务](assistant-reminders.md)和[空闲心跳](assistant-heartbeat.md)；运行细节、原始模型输出和人工分析保留在本地实验目录。

---

## 实验组成与隔离

使用已配置的真实中间件 HTTP 队列、MLLM、Embedding，以及独立临时 MySQL 8.4/MyVector。仅钉钉 Stream 来源和 OpenAPI 传输使用模拟器，仍经过实际入站解析、附件转换、可靠发布、任务消费、Core、持久化和交付代码。

三位合成用户分别承担项目协调、交期确认和预算审核。所有 SQL 人员与业务数据位于临时 schema；中央队列只使用该次运行唯一 userid。实验不发布用户或管理员全表，不修改真实 `.env`，不修改其他项目，不启用应用默认关闭的助理后台服务。临时运行器通过内存配置独立装配。

提醒时钟推进覆盖 24 小时内的到期事件；中央租约、心跳、数据库时间和模型调用使用真实时间。此方式验证一日场景，不能代替实际连续 24 小时运行、长期资源泄漏或真实钉钉权限验收。

## 场景与观测

| 场景 | 观察内容 |
| --- | --- |
| 入站 | 连续短消息合并、重复推送、图片转 PDF、整条拒收不支持的附件。 |
| 三用户沟通 | 姓名检索、两两助理通信、来源保留、预算与审批权限边界。 |
| 提醒 | 一次性/周期创建、到期先交给助理、选择通知或静默、删除周期提醒。 |
| 记忆 | 实际向量化与混合检索、找回预算修订、重新查看历史附件、重建消费者后恢复。 |
| 压力 | 三用户同时生成，忙碌期间追加九条短消息，检查合并、同用户串行与跨用户并发。 |
| 优先级 | 同时排入四种任务，检查提醒、用户、助理、心跳的领取顺序。 |
| 故障 | 发布与确认成功后丢失回执、机器人明确 429 后恢复、摘要输出校验与超时。 |

主压力场景以 low 推理强度运行，摘要保留实际配置 xhigh。该次历史实验将当时的 Core 总期限由默认 600 秒放宽为 1200 秒，独立模型请求超时仍由模型配置决定。当前实现已移除整轮任务总时限；此处保留实验发生时的条件，不代表当前运行配置。另用实际助理推理配置进行补验，不修改真实配置。

排队时间从首次成功发布到首次领取；处理时间取 SQL 接收到终态；端到端时间取发布到首次中央确认。压力运行的首片采集漏含服务端 `reasoning` 字段，因此展示为首正文/工具片段，不能称为完整 TTFT；medium 补验补齐原生推理字段。单轮模型耗时包含客户端并发限流等待，首片也不代表用户已收到完整回复。统计模型提出的工具调用与实际持久化验收分开，不能因模型提出 compact_context 就认定摘要成功。

## 复现与审阅入口

操作说明见[实验 README](../../../experiment/assistant-lifecycle/README.md)。运行器、产物和验证脚本均位于 `experiment/assistant-lifecycle/`，遵循项目实验目录不入版本追踪的约定，部署副本不包含这些文件。

每次运行保存配置快照、运行器快照、按时间追加的事件、模型实际请求/响应、流式片段及最终 SQL 快照。凭据与租约 token 不写入产物；图片 base64 以校验摘要替代，合成输入与任务 PDF 单独保留。

`review.html` 支持按用户、消息类别和关键词筛选，展示对话、任务耗时和可展开工具轨迹；`conversation.md` 是可直接阅读的对话记录。`analysis.md` 由分析者追加，区分事实、推断、失败和未验证范围。清理仅通过正常领取/确认接口处理已记录的实验任务，随后删除专用临时容器；中间件幂等回执按正常策略到期，不扫描或删除共享 Redis 键。

## 2026-10-24 结果

| 运行 | 结果 | 详细记录 |
| --- | --- | --- |
| 两用户基线 | 9 个任务完成，摘要任务触发实验 Core 的 240 秒期限；此前一次摘要规划返回不完整工具参数。 | [基线分析](../../../experiment/assistant-lifecycle/20261024-205721-2cf21a/analysis.md) |
| 三用户一日及压力 | 实际约 23 分 54 秒，33 个任务中 32 完成并确认，1 个摘要任务失败；峰值 3 用户、6 个待确认任务，无同用户执行重叠。 | [分析](../../../experiment/assistant-lifecycle/20261024-211140-dd559b/analysis.md)、[交互审阅](../../../experiment/assistant-lifecycle/20261024-211140-dd559b/review.html) |
| 实际 medium 补验 | 3 个任务全部完成，端到端约 32—79 秒；记忆恢复、未知信息边界、提醒创建后取消通过。 | [补验分析](../../../experiment/assistant-lifecycle/20261024-213552-848bc8/analysis.md)、[交互审阅](../../../experiment/assistant-lifecycle/20261024-213552-848bc8/review.html) |

压力批次 12 条短消息形成 6 个任务，其中忙碌期间追加的 9 条按用户各合并成 1 个后续任务。四类任务优先级、图片读取、真实向量化与检索、提醒、静默心跳、消费者重建及交付重试通过。主实验 65 条记忆全部完成向量化。

> **尚未通过：** xhigh 摘要规划持续输出，但在真实模型配置的 300 秒请求期限到达时失败，没有保存摘要检查点。失败任务不会自动重放或确认，故该用户后续消费需要受控处置。实验清理确认不算产品自动恢复，不能据此宣称全天稳定运行或摘要已经可用。

报告脚本和筛选交互通过离线执行检查；浏览器拒绝本地 file URL，未完成视觉预览。此次未修改应用代码或真实配置，不将此前 unittest 数量作为本轮新回归结果。真实钉钉及物理24小时连续运行仍未验收。
