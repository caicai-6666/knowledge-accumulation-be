# 独立 Agent Core 库接入实验

独立 Python 库位于 `/Users/caicai/Desktop/phenosolar/agent-core`，发行名 `agent-core`，导入名 `agent_core`。本次只提取库并在本项目执行隔离实验；生产个人助理和探索模式尚未切换为该依赖。

## 库的边界

库保留现有核心循环、原生工具与独立钩子、错误恢复、工作区、FIFO 压缩、主题摘要、记忆查询子智能体、专家求助与续问、文件/网页可选工具和 SSE 输出机制。

新增持久化 Agent 宿主，由库统一维护任务父链、分支、检查点、工作区版本、压缩窗口与重启恢复。消费者提供三类模型（日常、Embedding、外部专家）、可信身份、业务角色和工具，以及符合原子提交和混合检索契约的数据库适配器。随包提供 SQLite FTS5 + 向量参考实现。

业务配置、钉钉、员工、心跳生成/裁剪门禁、附件转换登记、日程及跨平台中间件仍由业务后端维护；不能直接替换依赖后宣称业务机制已自动迁移。

## 验证方式

1. 在新库运行迁移回归和库级测试，覆盖上下文清理、压缩、钩子隔离、持久化、并发 CAS、重启/分支、专家续问、记忆来源、流式取消与提交失败不交付。
2. 构建 wheel/sdist，在全新不继承系统依赖的虚拟环境中安装，验证所有库模块可导入，未加载后端 `app`。
3. 在当前项目的 `experiment/agent-core-package/` 使用合成项目资料执行真实模型实验，数据库显式位于各运行目录，不访问 `data/` 或业务 MySQL。
